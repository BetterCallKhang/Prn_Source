1.2. SQL Server & tạo database

Chọn 1 trong 2 cách:

Cách A — Docker (Linux/macOS/Windows đều được)

# 1) Chạy SQL Server 2022 (đổi mật khẩu nếu muốn, phải đủ mạnh: chữ hoa + số + ký tự đặc biệt)
docker run -d --name prn232-sql \
  -e ACCEPT_EULA=Y \
  -e MSSQL_SA_PASSWORD='Prn232@Exam123' \
  -e MSSQL_PID=Developer \
  -p 1433:1433 \
  mcr.microsoft.com/mssql/server:2022-latest

# 2) Đợi ~10-20s rồi kiểm tra
docker exec prn232-sql /opt/mssql-tools18/bin/sqlcmd \
  -S localhost -U sa -P 'Prn232@Exam123' -C -Q "SELECT @VERSION"

# 3) Tạo DB + bảng + seed data
docker cp src/db/init.sql prn232-sql:/tmp/init.sql
docker exec prn232-sql /opt/mssql-tools18/bin/sqlcmd \
  -S localhost -U sa -P 'Prn232@Exam123' -C -i /tmp/init.sql

# 4) Kiểm tra
docker exec prn232-sql /opt/mssql-tools18/bin/sqlcmd \
  -S localhost -U sa -P 'Prn232@Exam123' -C -d Prn232Exam \
  -Q "SELECT * FROM Account; SELECT * FROM Product;"
Container tên prn232-sql chỉ tạo 1 lần. Lần sau chỉ cần docker start prn232-sql. Muốn reset dữ liệu: chạy lại bước 3.

Cách B — SQL Server trên máy (Windows)

  • Cài SQL Server (bản Developer/Express) + SSMS hoặc Azure Data Studio.
  • Mở src/db/init.sql → Execute. Script tự tạo DB Prn232Exam.
  • Connection string dạng: Server=localhost;Database=Prn232Exam;Integrated Security=True;Trust Server Certificate=True

2.2. Checklist trước khi nộp

  • Build Release sạch: dotnet build -c Release không error.
  • Đúng số NuGet so với template đề cho (không tự thêm package mới).
  • Connection string nằm trong appsettings.json key MyCnn, không hard-code trong code.
  • JWT giống hệt nhau ở 2 API; không commit key thật nếu trường yêu cầu khác.
  • Port không trùng process khác; FE gọi đúng port API.
  • Tên folder publish đúng format đề: Q1_<MSSV>, Q2_<MSSV>.
  • Xoá bin/, obj/ trong folder nộp nếu đề yêu cầu giảm dung lượng.
  • Không còn code mẫu (WeatherForecast, Privacy...) và không còn TODO bỏ dở.
  • Restart sạch: tắt 3 app, chạy lại từ đầu, login + CRUD vẫn OK.

3.1. Query: Where / OrderBy / phân trang / search

src/Prn232.ProductApi/Controllers/ProductsController.cs

var query = _context.Products.AsQueryable();

// Lọc theo tên (đổi field theo đề)
if (!string.IsNullOrWhiteSpace(search))
{
    query = query.Where(p => p.Name.Contains(search));
}

// Đếm TRƯỚC khi Skip/Take
var total = await query.CountAsync();

var items = await query
    .OrderBy(p => p.Id)                  // đổi sang OrderByDescending / ThenBy nếu đề yêu cầu
    .Skip((page - 1) * size)
    .Take(size)
    .Select(p => new ProductDto
    {
        Id = p.Id,
        Name = p.Name,
        Price = p.Price,
        Description = p.Description,
        CreatedAt = p.CreatedAt
    })
    .ToListAsync();

return Ok(new ProductPageDto { Items = items, Page = page, Size = size, Total = total });
Nếu đề yêu cầu trả mảng trần (như đề mẫu Q1.1): bỏ ProductPageDto và return Ok(items);.
Ví dụ lọc + sort theo query string (đề mẫu Q2) 
[HttpGet]
public async Task<IActionResult> GetAll(
    [FromQuery] string? majorCode,
    [FromQuery] string? gender,
    [FromQuery] string? sortBy)
{
    var query = _context.Students
        .Include(s => s.Major)
        .AsQueryable();

    if (!string.IsNullOrEmpty(majorCode))
        query = query.Where(s => s.Major.Code == majorCode);

    if (!string.IsNullOrEmpty(gender))
        query = query.Where(s => s.Gender == gender);

    query = sortBy switch
    {
        "studentId" => query.OrderBy(s => s.StudentId),
        "studentDob" => query.OrderBy(s => s.Dob),
        _ => query.OrderBy(s => s.FullName)   // mặc định sort theo tên
    };

    var result = await query
        .Select(s => new
        {
            s.StudentId,
            FullName = s.FullName,
            MajorName = s.Major.Name,
            s.Dob
        })
        .ToListAsync();

    return Ok(result);
}

3.3. Controller CRUD tối thiểu

[ApiController]
[Route("api/products")]
[Authorize]
public class ProductsController : ControllerBase
{
    private readonly Prn232Context _context;
    public ProductsController(Prn232Context context) => _context = context;

    [HttpGet]
    public async Task<IActionResult> GetAll()
        => Ok(await _context.Products.Select(p => new { p.Id, p.Name, p.Price }).ToListAsync());

    [HttpGet("{id:int}")]
    public async Task<IActionResult> GetById(int id)
    {
        var entity = await _context.Products.FindAsync(id);
        return entity == null
            ? NotFound(new { message = $"Không tìm thấy id = {id}" })
            : Ok(entity);
    }

    [HttpPost]
    public async Task<IActionResult> Create([FromBody] SaveProductDto dto)
    {
        var entity = new Product { Name = dto.Name, Price = dto.Price, Description = dto.Description };
        _context.Products.Add(entity);
        await _context.SaveChangesAsync();
        return CreatedAtAction(nameof(GetById), new { id = entity.Id }, entity);
    }

    [HttpPut("{id:int}")]
    public async Task<IActionResult> Update(int id, [FromBody] SaveProductDto dto)
    {
        var entity = await _context.Products.FindAsync(id);
        if (entity == null) return NotFound();

        entity.Name = dto.Name;
        entity.Price = dto.Price;
        entity.Description = dto.Description;
        await _context.SaveChangesAsync();
        return Ok(entity);
    }

    [HttpDelete("{id:int}")]
    public async Task<IActionResult> Delete(int id)
    {
        var entity = await _context.Products.FindAsync(id);
        if (entity == null) return NotFound();

        _context.Products.Remove(entity);
        await _context.SaveChangesAsync();
        return Ok(new { message = "Đã xoá", id });
    }
}
Bảng nào có FK thì phải xoá theo thứ tự (con trước, cha sau), hoặc để DB báo lỗi FK rồi xử lý.

3.6. Tạo JWT

src/Prn232.AuthApi/Services/TokenService.cs

var claims = new List<Claim>
{
    new(JwtRegisteredClaimNames.Sub, account.Id.ToString()),
    new("username", account.Username),
    new("role", account.Role),
};

var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_jwt.Key));
var credentials = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);

var token = new JwtSecurityToken(
    issuer: _jwt.Issuer,
    audience: _jwt.Audience,
    claims: claims,
    expires: DateTime.UtcNow.AddDays(_jwt.ExpiryInDays),
    signingCredentials: credentials);

return new JwtSecurityTokenHandler().WriteToken(token);

3.7. Validate JWT trong Program.cs

var jwt = builder.Configuration.GetSection("Jwt").Get<JwtSettings>()!;

builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.MapInboundClaims = false;   // giữ claim "username", "role"
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            ValidIssuer = jwt.Issuer,
            ValidAudience = jwt.Audience,
            IssuerSigningKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(jwt.Key)),
            NameClaimType = "username",
            RoleClaimType = "role"
        };
    });
builder.Services.AddAuthorization();

// ... sau builder.Build():
app.UseAuthentication();   // PHẢI trước UseAuthorization
app.UseAuthorization();
Thiếu UseAuthentication() → mọi request có token vẫn bị coi là chưa đăng nhập (401).

<form method="post"> + tag helper là đủ: Razor tự chèn __RequestVerificationToken (ẩn) và cookie antiforgery. Đừng tự gửi form bằng JS mà quên token, sẽ bị 400.

PageModel tương ứng:

public class CreateModel : PageModel
{
    private readonly ApiClient _api;
    public CreateModel(ApiClient api) => _api = api;

    [BindProperty]
    public SaveProductDto Input { get; set; } = new();

    public string? ErrorMessage { get; set; }

    public async Task<IActionResult> OnPostAsync()
    {
        if (!ModelState.IsValid) return Page();

        try
        {
            var created = await _api.CreateAsync(Input);
            if (created == null)
            {
                ErrorMessage = _api.ErrorMessage;
                return Page();
            }
        }
        catch (UnauthorizedAccessException)
        {
            return RedirectToPage("/Login");
        }

        return RedirectToPage("./Index");
    }
}

3.12. Swagger có nút Authorize (Bearer)

builder.Services.AddSwaggerGen(options =>
{
    options.AddSecurityDefinition("Bearer", new OpenApiSecurityScheme
    {
        Name = "Authorization",
        Type = SecuritySchemeType.Http,
        Scheme = "bearer",
        BearerFormat = "JWT",
        In = ParameterLocation.Header,
        Description = "Dán token vào đây (không cần chữ Bearer)"
    });
    options.AddSecurityRequirement(new OpenApiSecurityRequirement
    {
        {
            new OpenApiSecurityScheme
            {
                Reference = new OpenApiReference
                {
                    Type = ReferenceType.SecurityScheme,
                    Id = "Bearer"
                }
            },
            Array.Empty<string>()
        }
    });
});
