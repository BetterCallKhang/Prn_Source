Khuyến nghị

Cách chính thức của .NET: cần cài tool (global) và package (trong project API) một lần, sau đó mỗi bảng chỉ cần 1 lệnh là có controller CRUD đầy đủ. Model phải được scaffold trước (DB-first). 


              
            


            
Chạy trong thư mục project API (vd: src/Prn232.ProductApi):


            

              

              
            


            
    
              
  • -name tên controller · -async action async · -api controller API.
    • 
              
  • -m class model đã scaffold · -dc DbContext · -outDir Controllers.

  • Tool sinh controller chưa có [Authorize] — thêm tay nếu API yêu cầu JWT.

Chạy file SQL để nạp database

            

            

              Mở file script đề cho, chạy bằng sqlcmd (hoặc SSMS → mở file → Execute).
              Script thường đã có CREATE DATABASE + USE, nên chỉ cần chạy 1 lần.
            

            

              

              
            

            
    
              
  • Windows auth: cờ -E — dùng user Windows hiện tại, không cần -U/-P.
    • 
              
  • SSMS: chọn Authentication = Windows Authentication, mở .sql rồi Execute (F5).
    • 
              
  • Script không tạo DB thì tạo trước: sqlcmd -S localhost -E -Q "CREATE DATABASE [<DbName>]".
    • 
              
  • Nếu đề yêu cầu đúng tên DB khác, sửa ô Database phía trên rồi chạy lại script (nếu cần).

Scaffold model (DB-first)

            

            

              Cài tool + package một lần, sau đó scaffold từ database vừa nạp.
              Bắt buộc có --no-onconfiguring để connection string nằm trong
              appsettings.json chứ không hard-code trong DbContext.
            


            

              

              
            


            

              

              
            


            
    
              
  • Chạy trong thư mục project cần có model (ví dụ src/Prn232.ProductApi).
    • 
              
  • -o Models: thư mục output · -f: ghi đè khi scaffold lại sau khi đổi đề.
    • 
              
  • Chỉ scaffold vài bảng: thêm -t Product -t Account.
    • 
              
  • Đổi tên DbContext: thêm -c Prn232Context.
    • 
              
  • Sau khi scaffold: xoá OnConfiguring nếu có, đăng ký AddDbContext trong Program.cs.

Lỗi thường gặp

            

            

              

                
                  
LỗiNguyên nhânCách xử lý

                
                
                  

                    A network-related or instance-specific error
                    Sai tên server / SQL Server chưa chạy
                    Kiểm tra service; SQL Express dùng .\SQLEXPRESS, Docker dùng localhost,1433.
                  

                  

                    Login failed for user ... (Windows)
                    User Windows chưa có login/quyền trên DB
                    SSMS → Security → Logins → thêm user; hoặc chuyển sang SQL auth.
                  

                  

                    The certificate chain was issued by an authority that is not trusted
                    SQL Server dùng certificate self-signed
                    Bật TrustServerCertificate=True (đã bật mặc định ở trên).
                  

                  

                    Cannot open database "X" requested by the login
                    Chưa chạy script hoặc sai tên DB
                    Chạy lại script; kiểm tra SELECT name FROM sys.databases.
                  

                  

                    dotnet ef: command not found
                    Chưa cài hoặc chưa có trong PATH
                    dotnet tool install --global dotnet-ef; thêm %USERPROFILE%\.dotnet\tools (Windows) hoặc ~/.dotnet/tools vào PATH.
                  

                  

                    Unable to connect... Windows auth khi DB chạy Docker/Linux
                    SQL Server trên Linux không hỗ trợ Windows Authentication
                    Chọn xác thực SQL Server ở trên và dùng user/password thật của container.
